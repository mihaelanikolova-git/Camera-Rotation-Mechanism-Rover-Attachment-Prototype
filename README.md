# Camera Rotation Mechanism – Rover Attachment Prototype
Parametric CAD model of a 360° camera rotation mechanism designed as a modular attachment for a mobile rover platform.

## Overview

This project presents the design and development of a compact camera rotation mechanism intended for integration with an autonomous mobile rover. The assembly provides continuous 360° horizontal rotation, allowing the camera to monitor the surrounding environment without requiring the rover itself to change orientation.

The mechanism was modeled entirely in SolidWorks using a parametric design approach, enabling components to be easily modified and adapted for different camera sizes or mounting configurations. 

The prototype is intended for future integration with a servo or geared motor, allowing remote or autonomous camera positioning for navigation, obstacle detection, and environmental monitoring.
